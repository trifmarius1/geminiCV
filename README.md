# Marius Trif — Software Test Engineer CV

Live site: **https://trifmarius1.github.io/geminiCV/**

Interactive web CV covering EV Body Control Modules, ASPICE, ISO 26262, Vector CAN tools, and AI-assisted testing.

## Run locally

**Prerequisites:** Node.js

1. Install dependencies: `npm install`
2. Start the app: `npm run dev`

The site is a static Vite + React app. Pushes to `main` rebuild and publish it on GitHub Pages automatically.
